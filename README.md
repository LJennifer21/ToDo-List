# Todo-List

# Overview
The To-Do List Web App is a simple yet effective task management tool built using HTML, CSS, and JavaScript. The app allows users to add, complete, and remove tasks in a clean, intuitive interface. Whether you're managing daily tasks or organizing your work, this app offers a straightforward way to stay on top of everything.

# Key Features
- **Add Tasks:** Easily input tasks with a simple interface.
- **Complete Tasks:** Mark tasks as complete using a checkbox, with visual feedback.
- **Remove Tasks:** Delete tasks as needed with a hover-to-delete feature.
- **Keyboard Support:** Add tasks quickly using the Enter key.
